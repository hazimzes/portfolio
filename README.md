# ▶ DEV_PORTFOLIO // HAZIM SHAH

A personal developer portfolio styled like a command-line terminal — absolute black, neon pink accents, monospaced type.

**View it live:** https://hazimzes.github.io/portfolio/

## // WHAT YOU'LL FIND

- **Hero** — full-screen name display with a live system clock and a glitch effect on hover.
- **PROJECT_INDEX** — clickable project cards. Each opens a full-screen panel with an extended write-up: the role played, what was built, the technical challenges behind it, and a photo gallery you can flip through with arrows, swipe, or keyboard.
- **XP_LOGS** — work history in a terminal-style timeline.
- **EDU_LOG** — education history, same format.
- **SYS_CAPABILITIES** — skills laid out as indexed cards with an animated memory bar.
- **INIT_CONTACT** — direct lines to reach me: email, LinkedIn, and a downloadable resume.

## // HOW TO USE IT

Scroll, click, explore. Sections fade in as you move down the page. Click any project card to open its full breakdown — the gallery supports prev/next buttons, thumbnails, keyboard arrows, and swipe. Use the top nav to jump straight to a section; the nav tracks where you are as you scroll.

No account, no downloads, nothing to install — it's a website.
